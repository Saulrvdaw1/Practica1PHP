# Cómo contribuir al proyecto

Este proyecto tiene ejercicios de PHP.

## Pasos para contribuir

- Descargar el repositorio.
- Crear una rama para realizar los cambios.
- Realizar las modificaciones necesarias.
- Comprobar que los ejercicios funcionan correctamente.
- Enviar una Pull Request con los cambios.

## Normas

- Mantener el código ordenado.
- Añadir comentarios cuando sean necesarios.
- Utilizar nombres claros para las variables.
- Explicar los cambios realizados.
